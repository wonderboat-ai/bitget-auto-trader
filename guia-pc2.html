Guia de instalação · PC2

Deixe o motor rodando 24 horas num segundo computador

Enquanto este PC fica livre para você desenvolver e testar melhorias, um segundo PC assume a operação contínua — com sua própria conta de testnet, chave de API e sem depender do OneDrive.

→
PC novo · PC2
Operação 24h

Repositório: wonderboat-ai/bybit-auto-trader (privado) Tempo estimado: 30–40 min Sistema: Windows
Como funciona a separação de contas — leia antes de tudo

O PC2 vai usar uma conta de testnet separada da que este PC (PC1) usa — não é só uma chave nova, é um cadastro novo mesmo (e-mail diferente em testnet.bybit.com). O saldo e as posições do PC2 ficam completamente independentes dos deste PC.

Na prática, isso elimina o risco que existiria se os dois PCs compartilhassem a mesma conta (os dois motores tentando gerenciar a mesma posição ao mesmo tempo). Com contas separadas: PC2 roda supervisor.py --live continuamente, 24h, na conta dele; PC1 fica livre para desenvolvimento e testes — inclusive com --live pontual, se precisar — sem nenhum risco pra operação do PC2.

Mesmo assim, é bom hábito não deixar um --live esquecido rodando aqui por longos períodos sem acompanhar — não por conflito com o PC2, mas porque é dinheiro (de teste) sendo movimentado sem supervisão.

O que você vai precisar

  • O PC novo, com Windows, ligado na internet
  • Uns 30–40 minutos livres
  • Sua conta do GitHub (a mesma que já é dona do repositório — usuário wonderboat-ai)
  • Um e-mail que você ainda não usou em testnet.bybit.com, para cadastrar a conta nova do PC2

Todo comando abaixo é para o PowerShell do Windows (menu Iniciar → procure "Windows PowerShell").

1

Instalar o Python

  1. Abra python.org/downloads e clique no botão amarelo "Download Python 3.x.x".
  2. Rode o instalador baixado.
  3. Na primeira tela, marque a caixinha "Add python.exe to PATH" — fica embaixo, antes do botão instalar.
  4. Clique em "Install Now" e espere terminar.
  5. Feche e abra o PowerShell de novo (precisa reabrir pra reconhecer o Python).
PowerShell · conferir instalação
python --version
Se der erroSe aparecer "não é reconhecido", o PATH não foi marcado — reinstale repetindo o passo 3.
2

Instalar o Git

  1. Abra git-scm.com/download/win e baixe o instalador.
  2. Pode ir clicando "Next" em tudo — as opções padrão servem.
  3. Feche e abra o PowerShell de novo.
PowerShell · conferir instalação
git --version
3

Instalar o GitHub CLI e entrar na conta

Isso permite baixar o código do repositório privado sem complicação.

  1. Baixe em cli.github.com (ou rode winget install --id GitHub.cli no PowerShell).
  2. Feche e abra o PowerShell de novo, depois rode o login abaixo.
PowerShell · login
gh auth login

Responda as perguntas nesta ordem:

  • "What account do you want to log into?" → GitHub.com
  • "What is your preferred protocol...?" → HTTPS
  • "Authenticate Git with your GitHub credentials?" → Yes
  • "How would you like to authenticate?" → Login with a web browser

Ele mostra um código de 8 caracteres e abre o navegador sozinho. Faça login com a mesma conta dona do repositório (wonderboat-ai) e cole o código.

ConfirmaçãoDe volta no PowerShell deve aparecer "Logged in as wonderboat-ai".
4

Baixar (clonar) o código

Vamos colocar o projeto direto na raiz do disco C:, fora de qualquer pasta do OneDrive — nem Documentos, nem Área de Trabalho, se essas pastas sincronizarem no PC novo.

PowerShell
cd C:\
gh repo clone wonderboat-ai/bybit-auto-trader BybitAutoTrader
cd C:\BybitAutoTrader

Confira que os arquivos apareceram com dir.

5

Criar o ambiente virtual e instalar dependências

PowerShell
cd C:\BybitAutoTrader
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
Como saber que está ativoCom o ambiente virtual ativo, a linha do PowerShell começa com (.venv). Sempre confira isso antes de rodar comandos python — se fechar e abrir o PowerShell de novo, rode .venv\Scripts\activate outra vez.
Erro de certificado/SSLComum com antivírus que inspeciona HTTPS (ex. Avast). Rode pip install pip-system-certs e tente de novo.
6

Criar uma conta separada e gerar a chave de API

Esta parte é só sua — conta e chave de API são credenciais, não é algo que eu deva criar ou digitar por você.

  1. Abra uma janela anônima/privada do navegador (Ctrl+Shift+N no Chrome/Edge) — assim você não usa por engano a sessão já logada da sua conta atual.
  2. Vá em testnet.bybit.com e cadastre uma conta nova, com um e-mail diferente do que você já usa lá.
  3. Confirme o cadastro (verificação por e-mail, se pedir) e faça login na conta nova.
  4. Vá em Gerenciamento de API (API Management).
  5. Crie uma chave — dê um nome que ajude a lembrar, como PC2-motor-24h.
  6. Permissões: marque leitura e negociação (Read-Write + Trade).
  7. Copie a API Key e o API Secret — o Secret só aparece uma vez.
Nunca habilitePermissão de saque (Withdraw). Não é necessária e não é segura.
Saldo de testeA testnet costuma dar um saldo de brinde automaticamente pra conta nova — você confirma isso no Passo 8, com diag_saldo.py.
7

Criar o arquivo .env com a chave nova

PowerShell
copy .env.example .env
notepad .env

Preencha assim, colando a Key e o Secret do passo anterior:

.env
ENVIRONMENT=testnet
BYBIT_TESTNET_API_KEY=cole_a_key_aqui
BYBIT_TESTNET_API_SECRET=cole_o_secret_aqui
BYBIT_MAINNET_API_KEY=
BYBIT_MAINNET_API_SECRET=
ANTHROPIC_API_KEY=
LOG_LEVEL=INFO

Salve (Ctrl+S) e feche o Bloco de Notas.

8

Testar antes de ligar de vez

Nunca pule esta parteConfirme que tudo funciona antes de deixar o motor mandando ordens de verdade.
PowerShell · confirma saldo/conexão
python diag_saldo.py

Deve mostrar o saldo da conta testnet sem erro. Se der erro, revise o .env — Key/Secret colados certos, sem espaço sobrando.

PowerShell · um ciclo de teste, sem ordem real
python main.py --once

Roda uma vez só, em modo seguro — não manda ordem nenhuma. Confira que não deu erro no final.

9

Deixar o PC sem suspender

Como o motor vai ficar rodando 24h, o PC não pode dormir sozinho:

  1. Menu Iniciar → Configurações → Sistema → Energia e bateria.
  2. Em "Tela e suspensão", mude tudo para Nunca — tanto a tela quanto a suspensão do PC.
Se for notebookFaça isso também para o modo "com bateria", não só "conectado na tomada" — ou deixe sempre no carregador.
10

Ligar de vez, 24 horas

PowerShell · início definitivo
cd C:\BybitAutoTrader
.venv\Scripts\activate
python supervisor.py --live

Esse é o comando definitivo: roda o motor de verdade (ordens reais na testnet) e, se o processo cair sozinho, o supervisor.py religa automaticamente.

Deixe a janela abertaPode minimizar, não pode fechar — é nela que o motor está rodando.
✋

Como parar com segurança

Clique na janela do PowerShell onde o motor está rodando e aperte Ctrl+C uma vez só. Isso avisa o motor pra fechar de forma limpa — ele termina o que está fazendo e registra o encerramento.

Nunca faça issoFechar a janela no X ou matar o processo pelo Gerenciador de Tarefas — isso conta como queda/crash, não como parada de propósito.
↻

Como atualizar o código no futuro

Quando uma melhoria for testada e aprovada aqui no PC1, ela vai (git push) pro mesmo repositório. Pra trazer isso pro PC2:

  1. Pare o motor com segurança (Ctrl+C, como acima) — nunca atualize com o motor rodando.
  2. Puxe a atualização:
PowerShell
cd C:\BybitAutoTrader
git pull

Religue com python supervisor.py --live.

Problemas comuns

"python não é reconhecido como comando"

O Python foi instalado sem marcar "Add to PATH". Reinstale marcando a caixinha (Passo 1).

Erro de certificado/SSL no pip install ou ao rodar o motor

Rode pip install pip-system-certs dentro do ambiente virtual ativo e tente de novo. Acontece com antivírus tipo Avast que inspeciona HTTPS.

"gh repo clone" pede senha e não aceita

O gh auth login do Passo 3 provavelmente não terminou certo. Rode gh auth status pra conferir; se não estiver logado, repita o Passo 3.

O motor não abre posição nenhuma depois de horas rodando

Na maioria das vezes não é bug — pode simplesmente não ter tido sinal de entrada ainda. Isso é esperado.
